# zion-pack

Pacote completo do framework **ZION** da Vision AI para Claude Code.

## Conteúdo

- **16 agentes** especializados (`agents/`) — vendas, marketing, financeiro, operação, RH, jurídico, email-executivo, proposta, relatório, reunião, conteúdo, trillion-board, tráfego-pago, tax, security, orquestra
- **22 skills** proprietárias (`skills/`) — incluindo trillion-board, tax-board, trafego-pago-auditor, weekly-sprint-planner, vision-premium-deck, security-audit, suite Instagram/mídia, e mais

## Instalação via marketplace (recomendado)

```
/plugin marketplace add Douglas8832/zion
/plugin install zion-pack@vision-zion
```
